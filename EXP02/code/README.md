# Experiment 2 UART

ESP32: run `ESP32/uart_led.py` on a compatible ESP32 with MicroPython. Connect a USB-to-TTL serial adapter at 3.3 V logic: adapter TX to GPIO16, adapter RX to GPIO17, and common GND. Power the ESP32 from its own USB connector as in the photo. Open the adapter COM port at 9600 baud, 8N1, no flow control, and type `1` or `0`. The normal ESP32 USB console is distinct from this UART2 connection.

STM32: `STM32/uart_led_user_code.c` contains the application supplied by the user on 1 November 2026, with short comments. Keep the original board-specific CubeIDE project and configure USART2 at 115200 baud, 8N1, no flow control, PA2 TX and PA3 RX, and PA5 GPIO output. The generated project must define `huart2`. Add this file to `Core/Src`, declare `void exp2_uart_led(void);` before `main`, then call `exp2_uart_led()` after HAL, clock, GPIO and USART2 initialization. Its loop waits for one character, echoes it, then handles ASCII `1` or `0`. Use the ST-LINK Virtual COM port shown in the experiment. The complete original project and .ioc are still absent. The screenshot target MCU is STM32F446RETx. Original adapter model and voltage setting are not specified. Hardware operation has not been tested here.
